Q&A card — NYC Housing Data Coalition

Posture everywhere: concede first, then locate what each tool adds. The substance is the public record + a transparent, measured linkage step; the graph and the LLM are tooling around it, everything labeled sourced vs. inferred.

"We live in SQL — what does the graph add?"

Concede: most of this IS SQL.
  • WoW is Postgres; the linkage (Splink) is DuckDB; every conditions aggregate is a GROUP BY.
  • The graph earns its place for the transitive, multi-relationship parts:
  • ① connected-component owner identity (recursive-CTE headache in SQL, one call in a graph);
  • ② heterogeneous N-hop traversal across owner/manager/address/deed layers;
  • ③ graph data science (centrality, community, link-prediction) runs natively.
SAY: "Count violations per owner → SQL wins. Everyone within 3 hops across four link types, ranked by centrality → that's the graph."
If pressed ("recursive CTEs / Apache AGE could do it"): concede — you can; it's a convenience/performance + agent/GDS substrate call, not a capability SQL lacks.

"We don't trust AI."

Agree — skepticism is correct.
  • Separate the two AIs: the model that decides who's the same owner is an auditable statistical linkage model (measured precision) — not a neural net.
  • The language model is only a read-only front door: it turns a question into a query and reports what came back. It never invents an answer.
  • Every element is labeled sourced vs. inferred; inferences are leads to verify.
  • Trust-builder: its main job is to not falsely connect people (the Miller un-merge).
  • Name the limit yourself: the blind accuracy eval isn't run yet.
SAY: "The model makes no claims — it reads the public record and labels every answer as fact or inference. If you don't trust the AI, ignore it and read the sourced records it points you to. The findings don't depend on it."

"How accurate is it?"

  • Precision ≈ 1.0, 0 cross-surname merges, on a 105-record hand-adjudicated gold set.
  • Recall / head-to-head vs WoW: not yet adjudicated — a ~530-pair blind eval is built, not run. Say this plainly.
  • Divergence (not accuracy): on ~39K shared buildings the two systems differ both ways (~780 / ~620).
SAY: "I can show it's precise on a labeled set. Whether it beats WoW where they disagree is exactly the eval I haven't run — and the help I'm here to ask for."

"Isn't naming people a privacy problem?"

  • All of it is public record (HPD/DOB/ACRIS); WoW already publishes these names with caveats.
  • We present it more accurately — the Miller map disaggregates a WoW over-merge (fairer to those individuals).
  • Leads, not verdicts; no legal determination; the demo is pinned to a public, AG-adjudicated figure (Croman).
SAY: "Same public records the field already publishes, presented more accurately and caveated — a lead to verify, never a verdict."

"How is this different from Who Owns What?"

  • It builds on WoW — credit it. Not a replacement.
  • Adds an owner-identity layer (de-fragment one owner's LLCs) and separates management vs. ownership vs. operational nexus.
  • Some of it (precision-first linkage, servicer/aggregator filters) is a candidate upstream PR to WoW.
SAY: "WoW answers 'who operates through this office'; I add 'who actually owns it,' kept as a separate, labeled layer — and I'd love to send some of it upstream."

"How does your :Portfolio relate to WoW's portfolio?" (the technical version)

It IS WoW's portfolio — plus one edge type.
  • Same construction: WCC + Louvain over WoW's landlords_with_connections, same name/address edges — plus CONNECTED_BY_SPLINK.
  • Edges only add → components only merge, never split: WoW's portfolios are preserved, its typo-fragmented ones collapse (Croman 6→1).
  • Don't confuse it with the owner-identity layer. :OwnerGroup is separate — connected components of the identity edges (splink|deed) only, no address glue, no Louvain. That's the "127 / who really owns this" number (the :Portfolio is broader — 135).
SAY: "Our Portfolio is WoW's — same WCC, same name/address edges — plus our splink links, so it only ever merges what WoW split. The 'who really owns this' number comes from a separate, stricter layer that drops the address glue entirely."

"Can we use it? Is it a product?"

  • No — it's a sabbatical prototype, not a shared service.
  • Read-only over public data; a conversational interface + these public examples.
  • I'm here for feedback and collaborators — especially to run the blind eval and to sanity-check the three-layer model.
SAY: "Not yet a service — a prototype I'm hoping to build the next part of with people in this room."
